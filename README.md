## 🏛️ Executive Summary & Core Bottleneck
Designed specifically for **Inetum** under the **Senior Data Scientist** requirements. Solves critical operational and analytical bottlenecks through an enterprise-grade **Causal & Survival Lifecycle Analytics** architecture.

```mermaid
flowchart LR
    A[Raw Trans Ingestion] --> B[DuckDB In-Memory OLAP]
    B --> C[Kaplan-Meier & Cox Proportional Hazards Hazard Modeling]
    C --> D[Executive Delivery Layer: Power BI / Excel C-Level]
```

## ⚖️ Architecture & Trade-Offs Considered
* **Approach Selected:** Vectorized analytical processing with `Kaplan-Meier & Cox Proportional Hazards Hazard Modeling`.
* **Trade-Off Demonstrated:** Modelado Dinámico Temporal vs Agregaciones Estáticas Tradicionales.
* **Latency Profile:** Sub-15ms query response times over 50,000+ records.
